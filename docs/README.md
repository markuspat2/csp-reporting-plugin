# CSP Reporting Plugin — Documentation

These guides walk you from installing the plugin to shipping a Content
Security Policy that fits your site. They're written to be read in order, but
each stands on its own.

| Guide | What it covers | Best for |
| --- | --- | --- |
| [Getting Started](getting-started.md) | Install the plugin, turn on reporting, and confirm it's working. | Everyone — start here. |
| [Understanding CSP](understanding-csp.md) | What a Content Security Policy is, why it matters, and what the pieces mean. | Anyone new to CSP. |
| [Crafting Your Policy](crafting-your-policy.md) | Use the violation logs to build a policy that fits your site, then enforce it. | The core workflow. |

New to Content Security Policy? Read **Understanding CSP** first, then follow
**Crafting Your Policy**. Just want it running? **Getting Started** gets you to
your first logged violation in a few minutes.

Looking for the developer reference (hooks, REST endpoint, WP-CLI, settings
table)? That lives in the [project README](../README.md).
